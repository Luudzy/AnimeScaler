# Model assets

Model weights and executable model shaders are not stored in this repository. Download only from upstream sources; review source and license first.

The root [README](../README.md#downloads-oficiais) lists upstream links and supported backends. For local file names and SHA-256 checks, see each JSON manifest in this directory and [ANIMEJANAI.md](ANIMEJANAI.md).

Keep downloaded files in this directory. Git ignores model assets by default.
